# Tableau CO2 Dashboard

## Overview

This project demonstrates the creation of a Tableau dashboard using CO2 emissions data.

The dashboard combines multiple visualizations to present CO2 emissions information in an accessible and organized format. It includes a geographic visualization showing average CO2 emissions per capita by country and a time-series visualization showing CO2 production by global region over time.

## Tools Used

- Tableau Public
- Excel
- Data Visualization
- Dashboard Design

## Dashboard Features

- Geographic visualization of CO2 emissions per capita
- Time-series visualization of CO2 production by region
- Year-based filtering
- Interactive legends
- Dashboard layout and formatting
- Visualization organization for stakeholder communication

## Skills Demonstrated
