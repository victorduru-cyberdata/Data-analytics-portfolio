# Tableau CO₂ Emissions Analysis

## Project Overview

This project explores CO₂ emissions per capita across countries from 2000 to 2011 using Tableau Public.

The analysis combines four datasets containing information on CO₂ emissions, energy use, total population, and GDP. The datasets were integrated using country and year fields to create a unified dataset for visualization and analysis.

## Objectives

* Compare CO₂ emissions per capita across countries and years.
* Integrate multiple datasets from different sources.
* Examine how emissions data can be analyzed alongside population, GDP, and energy-use information.
* Build an interactive Tableau visualization that allows users to explore emissions by year and country.

## Data Preparation

The project involved:

* Connecting four separate datasets in Tableau.
* Joining datasets using common country and year fields.
* Converting year fields to the appropriate date format.
* Converting energy-use data from string to decimal format.
* Converting GDP data from string to whole-number format.
* Working with datasets containing different time ranges.
* Using the overlapping period of 2000–2011 for the final analysis.

## Data Sources

The project uses four datasets covering:

1. CO₂ emissions
2. Energy use
3. Total population
4. GDP

The original datasets were provided as part of the Google Data Analytics coursework.

## Visualization

The final Tableau visualization uses color intensity to represent CO₂ emissions per capita by country.

A red-green diverging color palette was used, with higher CO₂ emissions represented by stronger red shades. A year filter allows users to explore changes in emissions across the 2000–2011 period.
